WP Stratos is a managed WordPress hosting platform built to remove the operational weight of running WordPress, whether that's one client site or fifty. Automatic updates, security patching, performance tooling, and email delivery are handled at the platform level, so the work left for you is running your business instead of babysitting a server.

## What is WP Stratos?

WP Stratos is a hosting environment built exclusively for WordPress, on infrastructure designed for WordPress workloads specifically rather than general-purpose cloud compute stretched to fit. That distinction matters more than it sounds. A generic cloud server has to support anything you throw at it. WP Stratos infrastructure only has one job, which means caching, PHP execution, and database tuning are already set up correctly before your first site ever launches.

Every site WP Stratos hosts runs with automatic failure detection and zero-downtime migration in the background, so hardware issues on our end get resolved before they ever reach your visitors. A web application firewall and automated DDoS mitigation sit in front of every site from the moment it's created, no add-on required. Core updates, security patches, and server-level configuration are handled without you needing to touch a terminal or manage a traditional control panel.

At the center of the platform sits the **WP Stratos Cloud Panel**, the web interface where you manage everything: creating and deleting sites, DNS and custom domains, backups, and staging environments, all from one dashboard. If you're running this as your own hosting business, the Cloud Panel is also where your day-to-day actually happens. Client onboarding that used to take an afternoon of server setup takes minutes.

SSL certificates are provisioned automatically for every domain you connect. They renew on their own. Nobody on your team has to remember an expiration date, and no visitor ever hits a broken padlock icon because someone forgot to renew a certificate three years running.

## The infrastructure underneath

You don't need to know any of this to use WP Stratos, but it helps to know what you're actually paying for.

Every site is backed by a global content delivery network with edge points of presence around the world, so a visitor in Sydney isn't waiting on a server response from Virginia. Traffic spikes are handled by burstable PHP resources that scale up automatically during a launch, a sale, or a post that unexpectedly goes viral, then scale back down once things settle. Backups run hourly for your database and daily for your full site files, and none of that counts against a storage quota or shows up as a line item you have to enable.

DNS is powered by enterprise-grade Cloudflare DNS under the hood, which is why nameserver changes and record edits propagate as fast as they do. If you connect your domain using WP Stratos-managed nameservers, Cloudflare also offers an optional proxy layer for individual DNS records. We recommend leaving it off. WP Stratos Edge Cache and the platform's built-in DDoS mitigation already sit in front of every site, and stacking a second proxy layer on top of that can create caching conflicts rather than solve anything. See [DNS Configuration](/domains/dns-configuration) for the details.
