The **welcome banner** is what you'll actually see when you open WP Stratos Environment from your WordPress admin sidebar. It's a dashboard-style overview, not a settings panel, built to answer "what's WP Stratos actually doing on this site" at a glance rather than to expose configuration you're meant to change here.

## What's on the Banner

<AccordionGroup>
  <Accordion title="Managed Plugins Overview">
    A summary card for each of the three managed plugins, WP Postman, Aero, and WP Stratos Environment itself, showing whether it's active and giving you a one-click link into that plugin's own settings screen. If you're trying to remember which plugin handles email versus caching versus platform identification, this is the fastest place to check.
  </Accordion>

  <Accordion title="At-a-Glance Settings">
    A handful of read-only or lightly configurable settings relevant to how the managed plugins behave together. This isn't a general-purpose settings screen, and it doesn't cover PHP version or server configuration, those live in the Cloud Panel, not here.
  </Accordion>
</AccordionGroup>

<Note>
  If you're looking to change your PHP version, that's done from the Cloud Panel's [Developer Settings](/cloud-panel/developer-settings), not from this plugin. Other PHP configuration values (memory limits, upload sizes, execution time) aren't self-service anywhere, plugin or Cloud Panel. Reach out to WP Stratos support at [missioncontrol@wpstratos.com](mailto:missioncontrol@wpstratos.com) if you need one of those adjusted for a specific domain.
</Note>

## Accessing the Welcome Banner

In your WordPress admin, click **WP Stratos Environment** in the left sidebar. The banner loads immediately, there's nothing to configure or navigate to first.
