## Hosting & Sites

<Accordion title="Can I host multiple WordPress sites?">
  Yes. Each WordPress site on WP Stratos is a separate, fully managed installation with its own database, file storage, and plugin set. The number of sites you can host depends on your current plan. Log in to **Cloud Panel → Sites** to see how many site slots are available under your subscription, or visit the pricing page to compare plans.
</Accordion>

<Accordion title="Can I import an existing WordPress site?">
  Yes. From the Cloud Panel, click **Add New**, choose **Import Existing WordPress Instance**, and enter your current site's URL. WP Stratos checks that WordPress is actually running there, then walks you through picking a server location and a migration method: the built-in migration plugin (recommended for most sites) or an FTP/SFTP-based transfer if the plugin route isn't an option for your current host. See [Migrate an Existing Site](/cloud-panel/migrate-a-site) for the full walkthrough.
</Accordion>

<Accordion title="Can I change my site's PHP version?">
  Yes. PHP version and PHP settings are managed per domain under a site's Advanced settings in the Cloud Panel. Changing the PHP version applies to every instance running on that domain, so test a version bump on staging first if you're not sure your theme and plugins are compatible. See [Developer Settings](/cloud-panel/developer-settings) for details.

<Accordion title="Does WP Stratos support WooCommerce?">
  Yes, WooCommerce is fully supported. WP Stratos applies recommended server settings for e-commerce workloads, and the Aero caching plugin automatically excludes cart, checkout, and account pages from the page cache to prevent session and order conflicts. See the [Cache Issues guide](/troubleshooting/cache-issues) for details on WooCommerce-specific caching behaviour.
</Accordion>

<Accordion title="Are WordPress core updates automatic?">
  Automatic update behavior for WordPress core, plugins, and themes is configurable under a site's Advanced settings in the Cloud Panel. If you'd rather review updates manually before they apply, especially for a client site where you don't want surprises, you can turn automatic updates off there and update on your own schedule.\*\*\*\* x
</Accordion>

<Accordion title="How do I secure my Cloud Panel account?">
  Turn on two-factor authentication under **My Account** in the Cloud Panel. You can also enable notifications for logins from new devices, and review or revoke active sessions from the Active Devices tab if anything looks unfamiliar. See [Security & Account Settings](/cloud-panel/security-and-account) for the full walkthrough.
</Accordion>

## Domains & SSL

<Accordion title="Do I need to transfer my domain to WP Stratos?">
  No. You can keep your domain registered at any registrar you prefer. Open **Change Domain** for your site in the Cloud Panel and choose either **Set DNS Records** (two A records and a CNAME, no nameserver change needed) or **Set Nameservers** (a WP Stratos-managed Cloudflare nameserver pair, generated for your specific domain). See [Connect a Domain](/domains/connect-domain) for the full walkthrough of both.
</Accordion>

<Accordion title="How long does SSL take after connecting a domain?">
  WP Stratos provisions SSL certificates automatically via Let's Encrypt once DNS propagation is confirmed. In most cases, your SSL certificate is issued within **a few minutes** of your domain resolving to WP Stratos. In cases where DNS propagation is slow, provisioning can take up to **24 hours**. You don't need to take any manual action, the process runs in the background.
</Accordion>

<Accordion title="Do I get a wildcard SSL certificate?">
  Each automatically provisioned Let's Encrypt certificate covers your root domain and the `www` subdomain. If you need coverage for additional subdomains, add each one as its own domain in the Cloud Panel and a certificate will be issued for it.
</Accordion>

<Accordion title="Should I enable the Cloudflare proxy toggle on my DNS records?">
  We recommend leaving it off. WP Stratos DNS runs on a Cloudflare-backed network, so the proxy toggle is there if you need it, but WP Stratos already provides Edge Cache and DDoS protection at the platform level. Running both at once creates two caching layers that don't coordinate with each other, and the usual result is a page that looks stale to some visitors and fresh to others. If a WordPress instance on that domain has Edge Cache active, the Cloud Panel warns you before the toggle takes effect. See [DNS Configuration](/domains/dns-configuration) for the full explanation.
</Accordion>

## Backups

<Accordion title="How often are backups taken?">
  Your database is backed up **every hour**, and your full site is backed up **once a day**, covering files and database together. You can also trigger a **manual backup** at any time from your site's Backups tab in the Cloud Panel, for example before making significant changes to your theme or installing a major plugin update.
</Accordion>

<Accordion title="How long are backups retained?">
  WP Stratos retains the last **30 days** of backups. After that window, older backups are removed automatically. If you need to preserve a snapshot beyond 30 days, for example before a major site redesign, download a copy of the backup to your own storage.
</Accordion>

<Accordion title="Can I download my backup files?">
  Yes. Go to **Cloud Panel → your site → Backups**, locate the backup you want, and click **Download**. The backup is packaged as a compressed archive containing your site files and a database export (depending on which backup you choose to download, you may only download the database, and not the files). You can use this archive to restore your site on any compatible WordPress host.
</Accordion>

## Plugins

<Accordion title="Can I install other plugins?">
  Yes. Any standard WordPress plugin from the WordPress.org repository or a premium marketplace is compatible with WP Stratos. Install plugins as you normally would from **WordPress admin → Plugins → Add New**, or use the built-in [Plugins & Themes](/cloud-panel/plugins-and-themes) manager in the Cloud Panel to install, update, and bulk-manage them without leaving your dashboard. The only consideration is avoiding multiple plugins that serve the same purpose as the managed plugins. Running a second caching plugin alongside Aero, for example, can create conflicts.
</Accordion>

<Accordion title="Why do WP Postman, Aero, and WP Stratos Environment keep reactivating?">
  These are managed plugins, core components of the WP Stratos hosting infrastructure. They are automatically reactivated as part of the platform's plugin update process to ensure your site remains stable and correctly configured after each update.

  If you need to disable a specific feature (such as page caching or outgoing email), do so from within the plugin's own settings rather than by deactivating the plugin. See the full explanation and workarounds in the [Plugin Reactivation guide](/troubleshooting/plugin-reactivation).
</Accordion>

<Accordion title="Can I use a different caching plugin?">
  You can install other caching plugins, but we strongly recommend using **Aero** as your sole caching solution. Running multiple caching plugins at once, Aero alongside WP Super Cache or W3 Total Cache, for example, frequently causes conflicts that result in stale pages, broken CSS, or performance regressions. Aero is optimised for the WP Stratos server environment and is fully supported by our team.
</Accordion>

<Accordion title="Can I use a different SMTP plugin?">
  Technically yes, other SMTP plugins are compatible with WordPress and will work on WP Stratos. However, **WP Postman** is specifically configured for the WP Stratos environment, integrates with platform-level email diagnostics, and is the only SMTP plugin the support team can fully troubleshoot. If you choose to use an alternative plugin, note that support assistance for third-party SMTP configurations may be limited.
</Accordion>

## Support

<Accordion title="How do I contact WP Stratos support?">
  You can reach out from the Cloud Panel: click your account menu in the top right corner and look for the support or help option there. For billing questions specifically, [billing.wpstratos.com](https://billing.wpstratos.com) has its own contact channel.
</Accordion>

<Accordion title="What information should I include in a support ticket?">
  To help the support team investigate quickly, include the following in every ticket:

  - **Your site's domain**, so the affected instance is easy to find.
  - **What's happening**, when it started, and anything you've already tried.
  - **A system info export**, available from the WP Stratos Environment plugin's Server Info page. See the [Server Info documentation](/plugins/wp-stratos-environment/server-info) for where to find it.
  - **Relevant error log lines**, if the issue is a fatal error or unexpected behavior. See [Logs](/cloud-panel/logs) for where to find them.

  Screenshots or screen recordings are also helpful for visual or intermittent issues.
</Accordion>
